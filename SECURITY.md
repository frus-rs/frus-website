# Security

The site is static: pages, pictures and a WebAssembly playground that runs in the reader's
browser. It has no accounts, no server-side code and stores nothing about its readers.

If you find a security problem anyway, for example a way to make a page run someone else's
script, **please do not open a public issue.** Report it privately through
[GitHub's vulnerability reporting](https://github.com/frus-rs/frus-website/security/advisories/new),
or email **kalyboskokou1@gmail.com** with `[frus-website security]` in the subject.

A problem in frus itself goes to [frus's security policy](https://github.com/frus-rs/frus/blob/master/SECURITY.md).
